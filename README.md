# my-miniapp-project
# ☕ Coffee Shop Management System

Website quản lý bán cà phê được phát triển theo phương pháp Agile/Scrum nhằm hỗ trợ quản lý sản phẩm, danh mục, khách hàng và đơn hàng.

---

## 📌 Giới thiệu

Dự án được thực hiện trong môn học Agile với mục tiêu xây dựng một website quản lý bán cà phê có đầy đủ các chức năng cơ bản của một hệ thống bán hàng.

---

## 🎯 Mục tiêu

- Quản lý sản phẩm.
- Quản lý danh mục.
- Quản lý khách hàng.
- Quản lý đơn hàng.
- Tìm kiếm sản phẩm.
- Đăng nhập và phân quyền người dùng.

---

## 🛠 Công nghệ sử dụng

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
