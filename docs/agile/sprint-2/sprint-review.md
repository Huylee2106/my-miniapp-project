# Sprint 2 - Sprint Review

## 1. Sprint Goal

Hoàn thiện các chức năng chính của hệ thống bao gồm quản lý sản phẩm, chi tiết sản phẩm, giỏ hàng và đặt hàng.

## 2. Completed User Stories

| ID | User Story | Assignee | Status |
|---|---|---|---|
| US06 | Quản lý sản phẩm | Huy | Done |
| US07 | Xem chi tiết sản phẩm | Khoa | Done |
| US08 | Thêm sản phẩm vào giỏ hàng | Huy | Done |
| US09 | Cập nhật giỏ hàng | Khoa | Done |
| US10 | Đặt hàng | Huy | Done |
| US11 | Xem lịch sử đơn hàng | Khoa | Done |

## 3. Completed Features

- Quản lý sản phẩm.
- Xem thông tin chi tiết sản phẩm.
- Thêm sản phẩm vào giỏ hàng.
- Cập nhật số lượng sản phẩm.
- Xóa sản phẩm khỏi giỏ hàng.
- Đặt hàng.
- Xem lịch sử đơn hàng.

## 4. Demonstration

Nhóm thực hiện demo các chức năng:

1. Đăng nhập vào hệ thống.
2. Xem danh sách sản phẩm.
3. Xem chi tiết sản phẩm.
4. Thêm sản phẩm vào giỏ hàng.
5. Cập nhật số lượng sản phẩm.
6. Xóa sản phẩm khỏi giỏ hàng.
7. Thực hiện đặt hàng.
8. Kiểm tra lịch sử đơn hàng.

## 5. Feedback

- Giao diện cần được cải thiện thêm.
- Cần kiểm thử nhiều trường hợp hơn.
- Cần xử lý tốt hơn các thông báo lỗi.
- Các chức năng chính đã đáp ứng yêu cầu của Sprint.

## 6. Sprint Outcome

Sprint 2 đã hoàn thành các User Story được lựa chọn trong Sprint Backlog. Nhóm đã hoàn thiện các chức năng chính và tạo nền tảng cho việc kiểm thử và hoàn thiện hệ thống.
