# Sprint 1 Review

## 1. Sprint Goal

The goal of Sprint 1 was to implement the basic foundation of
the e-commerce system, including user registration, login,
product listing and product details.

---

## 2. Completed User Stories

### US-01 – User Registration

**Status:** Completed

Users can create a new account by providing the required information.
The system validates the input and saves valid user information
to the database.

### US-02 – User Login

**Status:** Completed

Users can log in using valid credentials. Invalid credentials are
handled with an appropriate error message.

### US-03 – View Products

**Status:** Completed

Users can view the available products retrieved from the database.

### US-05 – View Product Details

**Status:** Completed

Users can select a product and view its detailed information,
including name, price, image and description.

---

## 3. Sprint Outcome

The Sprint 1 goal was achieved.

The system now provides the basic authentication and product
browsing functionality required for the next Sprint.

---

## 4. Demonstration

During the Sprint Review, the team demonstrated:

1. User registration.
2. User login.
3. Product listing.
4. Product detail page.
5. Database interaction.

---

## 5. Incomplete Work

No critical User Stories remained incomplete at the end of Sprint 1.

Additional improvements and shopping cart functionality will be
considered for Sprint 2.
