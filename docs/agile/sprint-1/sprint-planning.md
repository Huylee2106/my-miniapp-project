# Sprint 1 Planning

## 1. Sprint Information

**Sprint:** Sprint 1

**Duration:** 1 Week

**Sprint Goal:**

Build the basic foundation of the e-commerce system, including
user registration, user login, product listing and product details.

---

## 2. Selected User Stories

The following User Stories are selected from the Product Backlog
for Sprint 1:

- US-01 – User Registration
- US-02 – User Login
- US-03 – View Products
- US-05 – View Product Details

---

## 3. Sprint Tasks

### US-01 – User Registration

- Create User model.
- Configure User database table.
- Create Registration View.
- Create Registration Controller.
- Implement registration validation.
- Save new user information to the database.
- Test the registration function.

### US-02 – User Login

- Create Login View.
- Create Login Controller.
- Implement credential validation.
- Implement authentication/session.
- Handle invalid login information.
- Test successful and unsuccessful login.

### US-03 – View Products

- Create Product model.
- Configure Product database table.
- Create Product Controller.
- Retrieve products from the database.
- Create Product List View.
- Test product listing.

### US-05 – View Product Details

- Create product detail route.
- Retrieve product information by ID.
- Create Product Detail View.
- Display product image, name, price and description.
- Test product detail functionality.

---

## 4. Definition of Done

A User Story is considered Done when:

- The functionality has been implemented.
- The code has been tested.
- The functionality works without critical errors.
- The database operations work correctly.
- The code has been reviewed by the team.
- The completed work is committed to GitHub.

---

## 5. Sprint Goal

At the end of Sprint 1, users should be able to create an account,
log in to the system, view available products and view product details.
